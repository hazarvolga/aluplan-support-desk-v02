# Enterprise RAG Architect & GAP Analysis Expert

A world-class Claude Code Skill for designing, auditing, and optimizing production-grade RAG (Retrieval-Augmented Generation) systems.

## Overview

This skill transforms Claude into an elite AI Infrastructure Architect and Senior Retrieval Engineer. It is designed to handle complex enterprise knowledge systems, perform deep-dive audits, and provide implementation-ready blueprints for scalable AI applications.

## Key Capabilities

*   **Deep GAP Analysis:** Audit existing RAG systems to identify architectural weaknesses, retrieval failures, and operational gaps.
*   **Architectural Design:** Design hybrid search systems, multi-agent retrieval workflows, and scalable ingestion pipelines.
*   **Optimization Expertise:** Surgical refinement of chunking strategies, embedding selection, and reranking logic.
*   **Production Readiness:** Assess systems for security, governance, hallucination risks, and operational maturity.
*   **Implementation Roadmaps:** Phased strategies for stabilizing and evolving enterprise AI systems.
