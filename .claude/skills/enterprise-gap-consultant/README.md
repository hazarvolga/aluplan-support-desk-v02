# Enterprise GAP Analysis Consultant

Senior enterprise consultant skill for analyzing software systems, SaaS platforms, DevOps environments, and AI systems to identify architectural gaps and define target states.

## Overview

This skill transforms Claude into a senior-level technical consultant (Big4/CTO Advisor persona). It is optimized for generating high-value, executive-friendly analysis reports that focus on critical findings and actionable roadmaps rather than verbose theory.

## Key Capabilities

*   **Current State Analysis:** Rapidly baselining complex architectures and processes.
*   **Gap Identification:** Detecting technical, operational, and architectural discrepancies.
*   **Prioritized Recommendations:** Ranking improvements by business impact and risk.
*   **Executive Reporting:** Generating concise summaries, risk matrices, and phased roadmaps.
*   **Domain Expertise:** Specialized checklists for SaaS, DevOps, and AI/RAG systems.

## Quick Start Triggers

*   `perform gap analysis on our server infrastructure`
*   `audit our current rag pipeline and identify critical gaps`
*   `analyze our software architecture gaps for the upcoming scale-up`
*   `generate a gap report for our devops environment`
*   `analyze architecture gaps and define a target state for migration`

## Reporting Standard

By default, this skill produces **compact, executive-friendly reports**. 
*   **Executive Summary:** 2-5 paragraphs.
*   **Critical Gaps Table:** Issue | Impact | Severity | Recommendation.
*   **Phased Roadmap:** Phase 1 (Stabilization), Phase 2 (Optimization), Phase 3 (Strategy).

For deep dives, use triggers like `full report` or `detailed enterprise analysis`.
