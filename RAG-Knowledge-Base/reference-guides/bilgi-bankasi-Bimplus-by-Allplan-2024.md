# Bimplus by Allplan: The Ultimate OPEN BIM Collaboration Platform

Bimplus allows teams to access project data anywhere, at any time, efficiently communicate information needs, and collaborate with project partners in real time across the entire BIM lifecycle.

## What is Bimplus?
Bimplus is the central cloud-based data management platform offered by Allplan. It enables companies to incorporate project data from any construction industry software, merge, coordinate, review, and manage it effectively in a centralized federated model.

**Core Benefits:**
- **100% Coordinated and Consistent:** The common data environment minimizes unnecessary data exchanges and fragmented silos.
- **100% Up-to-Date:** A single source of truth provides instant status updates to all stakeholders.
- **100% Transparent:** Built-in powerful visualization tools, issue management (BCF), and task tracking.

## Key Features

### 1. Coordinate Project Data
Centrally aggregate models in a neutral cloud environment. Use the powerful web viewer to run clash-detection visually or automatically and assign attribute data reliably.

### 2. Manage Information History
Access documents, version histories, and multiple formats natively within the cloud environment without needing specialized desktop software. 

### 3. Change Management
Visualize any revision of any model. Compare the changes between an older model iteration and the new one in 3D to rapidly establish what was moved, deleted, or added.

### 4. Organize Projects Effectively
Maintain full control over all sub-models and track all open and closed tasks with an integrated task board and Kanban layout capabilities.

### 5. Easy BCF Communication
Visually communicate discrepancies via the BIM Collaboration Format (BCF). Take snapshots natively in the cloud to be resolved directly inside your authoring tool (Allplan, Revit, Archicad, etc.). Convey the exact BIM2Field design intent downstream to construction contractors securely.

### 6. Fully Cloud-Based
Accessible across tablets, phones, and PCs.
