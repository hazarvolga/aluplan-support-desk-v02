ALWAYS DISPLAY FIXTURES AS WIREFRAME



Question: In our views in the element plan (shop-ticket), the fixtures are shown as dashed lines (hidden) or in continus line for linear fixture against mixed line. How can we display them with the defined 2D foils?  Answer: The display of the fixtures can always be shown as a wireframe model ( 2D foil display) if this setting is defined in the general options. Just activate the following checkbox.
