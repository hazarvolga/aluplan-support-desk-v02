DATEN VON BIMPLUS PROJEKTEN SICHERN



Frage:  Wie können Dateien von BIMPLUS-Projekten gesichert werden?    Antwort:  Modelle:  
Sie können die Modell-Dateien (.ifc, .landxml, *.skp, ...) herunterladen, die hochgeladen wurden.  

 
 
Stammt ein Modell direkt aus Allplan oder einer anderen Applikation, so ist dieses Modell exportierbar.  
Share Projekte können separat gesichert werden.  

 
Dokumente:   Dateien können als zip File heruntergeladen werden. Eine Mehrfachauswahl ist möglich
 
Sonstiges
Folienshowshows  können als PDF exportiert werden und Issues (Mehrfachanwahl ist möglich) als BCF-Dateien. Dateien ,  die direkt mit dem Modell, Objekten, Issues, oder Strukturen verbunden wurden (also nicht als LINK) können nur einzeln herunter geladen werden. Dazu ist es erforderlich zu wissen, an welchen Objekten sie hängen,. Benutzerdefinierte Gebäudestrukturen mit Modell-Daten können als IFC exportiert werden.  
 
 
 
Hinweis:
Wenn bei den Dokumenten die Dateirevisionen auch gewünscht sind, können Sie diese einzeln anwählen und herunterladen. Dateien im Ordner MY DOCUMENTS sind von jedem Benutzer gesondert zu sichern, da diese für andere Benutzer nicht sichtbar sind.
