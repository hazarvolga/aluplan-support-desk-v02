# System Requirements: ALLPLAN 2026

## Hardware Requirements
### Minimum Requirements
- Intel/AMD Ryzen processor
- 8 GB RAM
- 20 GB free hard disk space
- OpenGL 4.2 compatible graphics board, 4 GB RAM (8 GB for Redshift), resolution 1920 x 1080

### Recommendation
- Intel Core i5, i7 or i9 / AMD Ryzen 5, 7, or 9 processor
- 32 GB RAM
- SSD storage
- Screen resolution up to 4K
- Vulkan 1.2 or OpenGL 4.5 compatible graphics board with >= 16 GB RAM (in accordance with certification)

## Software Requirements
### Supported Operating Systems
- Windows 11, version 24H2 (Edition LTSC 2024 also supported)
- Windows Server 2025, Standard-Edition
- Windows Server 2022, Standard-Edition
- Windows Server 2019, Standard-Edition

### Recommendation Operating System
- Windows 11, version 24H2

### Supported Data Servers for Data Storage
- Windows Server 2025
- Windows Server 2022
- Windows Server 2019
- Windows Storage Server 2022 for NAS

### Recommendation Data Server for Data Storage
- Windows Server 2025

## Important Warnings & Notes
- **NAS/DFS Warning:** NAS (Network Attached Storage) is supported only based on Windows Storage Server. DFS (Distributed File System) with ALLPLAN is not supported; it can lead to crashes, deadlocks, and deleted files.
- **Installation on MAC and Citrix:** Please note the additional system requirements for installation on Mac and on Citrix.
