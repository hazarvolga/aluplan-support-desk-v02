# System Requirements: SCIA Engineer 2026

## Hardware Requirements
### Minimum Requirements
- Intel Core i7 / AMD Ryzen 5 processor or similar
- 16 GB RAM
- SSD Storage, 5 GB free hard disk space
- Graphics Controller 256 MB, OpenGL 2.1
- Resolution: Full High Definition (up to 4K is supported)

### Recommendation
- Intel Core i7 / AMD Ryzen 7 or similar
- 32 GB RAM or more
- SSD storage, 5 GB or more hard disk space
- Graphics controller 4 GB or more
- Resolution: Full High Definition (up to 4K is supported)

## Software Requirements
### Supported Operating Systems
- Windows Server 2019, Standard-Edition
- Windows 10 (64-bit)
- Windows 11 (64-bit)

### Recommendation Operating System
- Windows Server 2019, Standard-Edition
- Windows 11 (64-bit)
