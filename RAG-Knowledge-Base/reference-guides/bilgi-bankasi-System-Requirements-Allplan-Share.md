# System Requirements: ALLPLAN Share

## Network Requirements
- An internet connection that is stable and uninterrupted.
- **Minimum Requirements:** 10 Mbit/s for upload; 20 Mbit/s for download. The latency must be less than 50 milliseconds (you can check this by means of Allplan Performance Diagnostics, for example).
- **Recommended Requirements:** 50 Mbit/s for upload; 100 Mbit/s for download. The latency must be less than 10 milliseconds.
- Current network drivers.
- Network connections based on LAN (better than WLAN).

## Local File Storage Folder
- If possible, use a local (SSD) hard drive for the local file storage folder; network drives slow down access. 
- The local file storage folder **must not be shared** between several users; this might cause massive problems. The Services window shows the path of the local file storage folder.
- You can find information on how to change the path of the local file storage folder in a FAQ on Allplan Connect (search term: "local file storage folder Allplan Share").

## Hardware Requirements
- The hardware requirements are the same as those for Allplan.

## Further Requirements
- You have an Allplan Bimplus/Allplan Connect/Allplan Campus account.
- An Allplan Bimplus team is available.
- To create Allplan Share projects, you have to be the team owner or team administrator of the Allplan Bimplus team.
- You have one or more Allplan Share licenses.
