# Allplan 2022 - Manual: Basics

## Welcome
Welcome to Allplan 2022, the high-performance CAD program for architects and civil engineers. In this manual, you will familiarize yourself with the user interface and the basic tools of Allplan 2022.

## Allplan User Interface
When you start Allplan, you see the Allplan window with the user interface.

### Elements of the Interface
- **Actionbar**: Contains all Allplan tools grouped by tool groups, task areas, and roles.
- **Palettes**: Properties, Wizards, Library, Objects, Planes, Issue Manager, Connect, and Layers.
- **Viewports**: Used for editing the model in different views and perspectives.
- **Status Bar**: Located at the bottom, showing coordinates, scale, and length units.

## Basic Approach: Using the Mouse

### Left Mouse Button
| Method | Action |
| :--- | :--- |
| Click element | Selects the element with handles. |
| Shift+click element | Selects an entity group or a symbol with handles. |
| Ctrl+click element | Selects an additional element or cancels selection. |
| Double-click element | Displays element properties. |

### Middle Mouse Button
- **Double-click**: Selects display scale to see all visible elements.
- **Click and drag**: Pans in the active viewport.

### Right Mouse Button
- **Click element**: Displays shortcut menu for the element.
- **Double-click in workspace**: Opens the Layer dialog box.

## Precision Drawing
Allplan allows entering length values and coordinates as real values. It includes tools like:
- **Point Snapping**: End points, midpoints, intersection points.
- **Grid Dimensions**: Rasterize length option for precise placement.
- **Track Lines**: For intuitive design without construction lines.

## Structuring and Managing Data
- **Building Structure**: Logical hierarchy for projects (BIM basis).
- **Drawing Files**: Actual design and data creation happens here (up to 1024 open files).
- **Layers**: Additional means of structuring design entities within drawing files.

### Layer Access Rights
| Icon | Access Right | Explanation |
| :--- | :--- | :--- |
| Red | Current | The layer on which you draw. |
| Yellow | Modifiable | Elements are visible and can be modified. |
| Gray | Visible, frozen | Elements are visible but cannot be modified. |
| White | Hidden, frozen | Elements are not visible and cannot be modified. |
